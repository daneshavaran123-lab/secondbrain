# Quickstart: راستی‌آزمایی جستجوی یکپارچه

## پیش‌نیاز

- Postgres محلی (پورت 5433) با `backend/src/db/schema.sql`، backend روی 3100، و build پیش‌نمایش frontend روی 8080.
- دو کاربر آزمون (A و B). اسکریپت API کاربرها را می‌سازد.

## ۱. آزمون‌های سریع

```bash
cd backend && npm test                   # شامل test/search.test.js: یکسان‌سازی، کلیدواژه، تکه متن، سازنده پرسش
cd frontend && npx tsc --noEmit -p tsconfig.app.json && npx eslint src && npx vitest run
TZ=Asia/Tehran npx vitest run && npx vite build
```

انتظار: همه سبز؛ tsc بدون خطای تازه؛ eslint بدون error.

## ۲. API با دو کاربر (`agent-test/search-api.mjs`)

1. A برای **هر** نوع در [data-model.md](./data-model.md) یک مورد با کلمه «کلاته» می‌سازد (از `/db` یا `user_collections`).
2. `GET /search?q=کلاته` برای A → یک گروه برای هر نوعی که `palette` دارد؛ هر `path` با مسیر جدول R8 در
   [research.md](./research.md) یکی است (SC-003).
3. همان پرسش برای B → `total: 0` (SC-005). B موردی با «کلاته» می‌سازد؛ A همچنان فقط موردهای خودش را می‌بیند.
4. گونه‌های نوشتاری (SC-004): «كلاته»، «کلاته‌»، «ميخواهم»، «می خواهم»، «1405» در برابر «۱۴۰۵»، «کلاته آب» → پیدا؛
   «کلاته برق» → پیدا نمی‌شود.
5. رتبه: مورد با «کلاته» در عنوان بالاتر از مورد با «کلاته» فقط در متن.
6. `limit`/`type`: ۷ نیاز منطبق → گروه با ۵ مورد و `total: 7`؛ `?type=need&limit=20` → ۷ مورد.
7. پرسش یک‌حرفی → `groups: []`؛ `type` ناشناخته → ۴۰۰؛ بدون توکن → ۴۰۱؛ `%` و `_` در پرسش فقط همان نویسه را می‌گیرند.
8. کارایی (SC-002): ۵٬۰۰۰ مورد برای A → زمان پاسخ کمتر از ۳۰۰ms.

## ۳. مرورگر (`verify-search.cjs`)

1. ورود A، Ctrl+K، تایپ «کلاته» → گروه‌ها با نام فارسی، تاریخ شمسی، تکه متن؛ ناحیه اعلام تعداد.
2. Enter روی نیاز → `/organizational/khadim-e-khalgh/needs?highlight=…` و همان کارت نمایان و برجسته.
3. «بیشتر» در گروهی با بیش از ۵ مورد → تا ۲۰ مورد.
4. «زززز» → «چیزی پیدا نشد» و «از دستیار بپرس».
5. backend خاموش → پیام «جستجو در داده‌ها الان در دسترس نیست» و صفحه‌ها همچنان پیدا می‌شوند.
6. موبایل ۳۹۰px: باز شدن از دکمه جستجوی نوار بالا، بدون اسکرول افقی.

## ۴. دستیار

با LLM ساختگی (`agent-test/fake-llm.mjs`) فراخوانی `search_brain` با `query: "کلاته"` و `sources: ["need"]` →
نتیجه با `path` و وضعیت نیاز. پاسخ با LLM واقعی آزموده نمی‌شود (در گزارش ذکر شود).
