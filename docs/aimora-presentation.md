# ایمورا (Aimora)
### دستیار اجرایی هوشمند برای مدیران و متخصصان

---

## معرفی محصول

**ایمورا** یک پلتفرم جامع مدیریت شخصی و سازمانی است که با بهره‌گیری از هوش مصنوعی، تمام جنبه‌های کاری و شخصی مدیر را در یک محیط یکپارچه گرد هم می‌آورد. کاربر بدون نیاز به ابزارهای پراکنده، از تقویم تا واگذاری وظایف، از مدیریت دانش تا ارسال پیامک — همه چیز را از یک پنل کنترل می‌کند.

> **دسترسی**: [aimora.app](https://aimora.app)

---

## ماژول‌های اصلی

| ماژول | توضیح |
|---|---|
| 🤖 **دستیار هوشمند** | دستورات زبان طبیعی فارسی — بدون فرم، فقط بگو «جلسه فردا ساعت ۱۰» |
| 📅 **تقویم حرفه‌ای** | مدیریت قرارها، یادآورها و جلسات با تشخیص تداخل زمانی |
| ✅ **مدیریت وظایف** | وظایف شخصی، حرفه‌ای و سازمانی با سطح اولویت‌بندی |
| 🔗 **واگذاری وظایف** | تفویض اختیار به تیم با پیگیری وضعیت و اطلاع‌رسانی SMS |
| 💡 **بانک ایده‌ها** | ثبت، دسته‌بندی و تحلیل هوشمند ایده‌ها (SWOT، بوم کسب‌وکار) |
| 🧠 **مدیریت دانش** | ذخیره مقالات، کتاب‌ها، صورتجلسات و یادداشت‌های حرفه‌ای |
| 👥 **مدیریت مخاطبین** | مخاطبین شخصی و حرفه‌ای با امکان شبکه‌سازی |
| 🏢 **مدیریت سازمان** | ساختار سازمانی، اعضا، ماموریت‌ها، OKR و ارزیابی عملکرد |
| 📊 **گزارش‌های هوشمند** | تحلیل رفتار و عملکرد کاربر با نمودارهای تعاملی |
| 🏃 **سلامت و بهره‌وری** | ثبت ورزش، خواب، تغذیه و عادت‌های روزانه |
| 📄 **رزومه حرفه‌ای** | ساخت و مدیریت رزومه با چندین قالب آماده |
| ⚖️ **امور حقوقی** | مدیریت پرونده‌های حقوقی و جلسات دادگاه |
| 🌱 **مسئولیت اجتماعی** | پیگیری پروژه‌های CSR سازمان |
| 📱 **ارسال پیامک** | ارسال پیامک مستقیم از دستیار هوشمند |
| ✉️ **ایمیل حرفه‌ای** | نگارش ایمیل‌های حرفه‌ای با کمک هوش مصنوعی |
| 📖 **دفتر شخصی** | دل‌نوشته، شکرگذاری روزانه و خاطرات |

```
                   │
                   ▼
```

## فلوی واگذاری وظیفه

```
مدیر ایجاد وظیفه می‌کند
        │
        ▼
انتخاب مسئول اجرا (از مخاطبین)
        │
        ▼
ارسال خودکار SMS اطلاع‌رسانی به مسئول
        │
        ▼
پیگیری وضعیت در پنل واگذاری
        │
   ┌────┴────┐
   ▼         ▼
انجام شد   در انتظار
   │
   ▼
گزارش به مدیر
```

```
  • اقدامات پیشنهادی
        │
        ▼

```

## مزیت‌های رقابتی

- **زبان فارسی کامل**: تمام رابط کاربری و دستیار هوشمند ۱۰۰٪ فارسی
- **بدون فیلتر**: سرور ایرانی، بدون نیاز به VPN
- **یکپارچگی**: یک پلتفرم به جای ۱۰ ابزار مختلف
- **هوش مصنوعی محور**: به جای کلیک کردن، فقط صحبت کنید
- **مناسب سازمان**: مدیریت تیم، سلسله مراتب و واگذاری وظایف
